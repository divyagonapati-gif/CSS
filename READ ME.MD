# Responsive CSS Landing Page

## Description

This project is a responsive landing page developed
using HTML5 and CSS3.

The project demonstrates important CSS concepts such
as Flexbox, responsive design, hover effects,
navigation styling, cards and media queries.

## Technologies Used

- HTML5
- CSS3

## CSS Concepts Used

- CSS Selectors
- Box Model
- Flexbox
- Media Queries
- Hover Effects
- Transitions
- Gradients
- Responsive Design
- Positioning
- Typography

## Features

- Responsive navigation bar
- Hero section
- About section
- Services section
- Contact section
- Service cards
- Hover effects
- Mobile responsive layout
- Footer

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `code/index.html` in a web browser.
4. The website will be displayed.
5. Resize the browser window to test responsiveness.
